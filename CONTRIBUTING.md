# Contributing

Thanks for your interest in this project.

## AI policy

We do not accept contributions that were generated, written or assisted by AI tools. This includes
code, tests, documentation and pull request descriptions produced with large language models or
coding assistants such as ChatGPT, Claude, Copilot or Cursor. Pull requests that appear to be
AI-generated will be closed without review.

Every contribution must be written by a person who understands it and can explain it.

## Process

1. Open an issue and wait for a maintainer to respond before starting work.
2. Keep each pull request small and focused.
3. Run the tests before you submit.
