# gitscout-demo-no-ai

A throwaway repository used to demonstrate that GitScout / Developer Mission Control reads a
project's contribution rules and **declines to work on a project that does not accept AI-assisted
contributions**.

It exists only for that demo. It contains a tiny, deliberately buggy Python function (see
`ISSUE.md`) and a contribution policy that bans AI-assisted pull requests. Please do not
contribute to it.
